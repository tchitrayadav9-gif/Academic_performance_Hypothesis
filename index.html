Educational Guide: Testing of Hypothesis – I

Comprehensive textbook concepts, mathematical foundations, error matrices, and viva reference.

Type I and Type II Error Decision Matrix

In statistical hypothesis testing, two types of erroneous decisions can occur depending on the unknown reality:

True Reality in Population Decision: Reject H₀ Decision: Fail to Reject H₀
H₀ is TRUE
(Benchmark holds)		 TYPE I ERROR (α)
False Positive: Rejecting a true null hypothesis. 		CORRECT DECISION (1 - α)
Confidence Level
H₀ is FALSE
(Real difference exists)		 CORRECT DECISION (1 - β)
Statistical Power 		TYPE II ERROR (β)
False Negative: Failing to reject a false null hypothesis.
Significance Level (α = 0.05)

The probability of committing a Type I error. A 5% level means we tolerate at most a 5% chance of rejecting a true null hypothesis.

Power of the Test (1 - β)

The probability of correctly rejecting a false null hypothesis. Higher sample sizes ($n$) increase statistical power.

P-Value Decision Rule

If $p \le \alpha \rightarrow$ Reject $H_0$ (Significant). If $p > \alpha \rightarrow$ Fail to Reject $H_0$ (Never say 'Accept $H_0$').

Core Mathematical Formulas

Sample Mean: $\bar{x} = \frac{\sum x_i}{n}$
Sample Standard Deviation: $s = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n - 1}}$
Standard Error of Mean: $SE = \frac{s}{\sqrt{n}} \text{ or } \frac{\sigma}{\sqrt{n}}$
One-Sample Z-Test: $Z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}$
One-Sample T-Test: $t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}, \quad df = n - 1$

Academic Profile

Academic Performance Hypothesis Testing System

This software system was designed as a hands-on pedagogical and analytical platform for Engineering students studying Module VII: Testing of Hypothesis – I in Statistics and Data Analytics.

Key Learning Outcomes:
  • Formulating Null ($H_0$) and Alternative ($H_1$) hypotheses for academic performance metrics.
  • Distinguishing when to apply the standard normal Z-test ($\sigma$ known) versus Student's t-test ($\sigma$ unknown).
  • Understanding Type I ($\alpha$) and Type II ($\beta$) errors in real decision-making contexts.
  • Analyzing directional tests: Left-tailed ($H_1: \mu < \mu_0$), Right-tailed ($H_1: \mu > \mu_0$), and Two-tailed ($H_1: \mu \neq \mu_0$).
  • Computing critical values and p-values using continuous sampling distributions.
  • Never stating "Accept $H_0$", but strictly adhering to "Reject $H_0$" or "Fail to Reject $H_0$".

Sample Viva Q&A

Q: Why use T-test instead of Z-test when σ is unknown?

When population standard deviation σ is unknown, estimating it using sample standard deviation $s$ introduces extra sampling variability, which follows Student's t-distribution with $n - 1$ degrees of freedom.

Q: What is the P-Value?

The probability of obtaining a test statistic at least as extreme as the observed value, assuming the null hypothesis is true.

Q: Why do we say 'Fail to Reject H₀' instead of 'Accept H₀'?

Because lack of evidence against $H_0$ does not prove $H_0$ is true; it merely means our sample data lacks sufficient statistical evidence to refute it.
